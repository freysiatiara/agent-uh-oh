# The Agent's Uh-Oh

One word an agent says when it has no idea what to do: **Overthinking**.

The agent isn't broken, glitching, or lost — it is stuck in its own head,
turning the same question over and over while the task waits. That is the
whole joke: a machine caught mid-task, stalling out loud.
